# AYYAN AI - Creative & Reasoning Intelligence Suite

An authentic, responsive **AYYAN AI Web UI** (inspired by Claude.ai) hosted for free on GitHub Pages that connects to your remote cloud-hosted Ollama backend (Google Colab / Kaggle).

---

## 🌟 Core Capabilities Built into AYYAN

1. **🎨 High-Definition AI Image Generation**: Generate stunning visuals using modern FLUX/SDXL models directly in chat or with `/image <prompt>`.
2. **📊 PowerPoint (.pptx) Slide Deck Creation**: Generates downloadable multi-slide presentations with formatting via `pptxgenjs` or `/ppt <topic>`.
3. **📄 Instant PDF Document Export**: Generates styled PDF reports on-the-fly via `jsPDF` or `/pdf <title>`.
4. **📝 Word (.doc) Document Creation**: Instant Word document generation via `/doc <topic>`.
5. **🎥 Video / Animation Stills**: Visual animation concepts via `/video <prompt>`.
6. **📎 Full Document & Code Analysis**: Upload and analyze PDFs, Python, JavaScript, JSON, Markdown, and text files.
7. **🗂️ Multi-Session Chat Persistence**: Complete conversation history saved locally in your browser.
8. **⚡ Artifacts Side Drawer**: View, copy, or download code snippets and reports in a dedicated split-screen view.
