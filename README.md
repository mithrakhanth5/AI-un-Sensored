# AI Un-Sensored (Claude UI + Cloud Ollama)

A sleek, responsive **Claude.ai-style Web UI** hosted for free on GitHub Pages that connects to your remote cloud-hosted Ollama backend (Google Colab / Kaggle).

---

## 🚀 How to Enable GitHub Pages (Free Live Web Link)

1. Open this repository on GitHub: `https://github.com/mithrakhanth5/AI-un-Sensored`
2. Go to **Settings** → **Pages** (on the left menu).
3. Under **Build and deployment** > **Branch**:
   - Select **`main`** (or `master`)
   - Select folder: **`/ (root)`**
   - Click **Save**.
4. In ~60 seconds, GitHub will give you a public live URL:
   `https://mithrakhanth5.github.io/AI-un-Sensored/`

---

## 📱 How to Use on Mobile & Desktop

1. Open your live GitHub Pages link: `https://mithrakhanth5.github.io/AI-un-Sensored/`
2. Click the **Connection Settings** gear in the sidebar.
3. Paste the **Cloudflare Tunnel URL** generated by your Google Colab notebook (e.g. `https://xxxx.trycloudflare.com`).
4. Select your model (e.g. `qwen2.5:7b` or `whiterabbitneo`).
5. Start chatting with your remote cloud AI directly from any phone or computer!
